# Klarfeld

Statische Website für Klarfeld media.

## Struktur

- `index.html` — Startseite
- `leistungen.html` — Leistungs-Hub
- `zielgruppen.html` — Zielgruppen-Hub
- `methode.html` — Methoden-Hub
- `angebote.html` — Angebots-Hub
- `style.css` — Layout und Design
- `script.js` — Navigation und dezente Interaktionen
- `assets/` — Bild- und Logo-Assets
